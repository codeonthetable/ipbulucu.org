# IP Bulucu - Google Chrome Uzantısı (Extension)

Bu eklenti, kullanıcıların tek tıkla IP adreslerini, santral konumlarını, ISP operatörlerini ve ağ güvenlik durumlarını tarayıcı araç çubuğundan görmelerini sağlar.

## Google Chrome Web Mağazasına Yükleme Adımları:
1. `chrome-extension` klasörünün içeriğini bir `.zip` dosyası haline getirin.
2. [Chrome Geliştirici Paneli](https://chrome.google.com/webstore/devconsole/)'ne gidin.
3. "Yeni Öğe" butonuna tıklayıp `.zip` dosyasını yükleyin.
4. Açıklama kısmına `https://ipbulucu.org` web sitesi linkinizi ekleyin.
5. Onaylandığında Google Chrome Mağazası üzerinden **Domain Otoritesi (DA) 96 olan en güçlü backlinklerden birini** sitenize kazandırmış olursunuz!
